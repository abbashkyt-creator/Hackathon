This directory contains only the game-owned HTML5/Three.js source assets needed
to run Smash Room locally. The Poki page shell, Poki SDK, advertisements,
analytics, tracking, consent UI, and all source-site network calls are excluded.
The local launcher deliberately does not create a PokiSDK object, so the
source's optional ad and telemetry branches remain inactive.
